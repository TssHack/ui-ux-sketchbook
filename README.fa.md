# ✎ ui-ux-sketchbook

**طرح روی کاغذ را به یک محصول واقعی و ریسپانسیو تبدیل کنید که هنوز ظاهر دست‌کشیده دارد.**

یک اسکیل برای ایجنت‌های برنامه‌نویسی: **Claude Code، Codex، Cursor، Hermes Agent** و هر ایجنتی که فایل `SKILL.md` را می‌خواند. یک زبان طراحی در سه نسخه: **جاوااسکریپت ساده**، **React / Next.js** و **فلاتر** (اندروید، iOS، وب و دسکتاپ).

[دموی وب](https://tsshack.github.io/ui-ux-sketchbook/) · [دموی فلاتر](https://tsshack.github.io/ui-ux-sketchbook/flutter/) · [English](README.md)

## چرا؟

وقتی از یک ایجنت می‌خواهید «این طرح دستی را بساز»، معمولاً یکی از دو چیز تحویل می‌گیرید. یا **تصویری از طرح**: صفحه‌ای ثابت که نقاشی را کپی کرده، چیزی در آن کار نمی‌کند و در موبایل به هم می‌ریزد. یا **یک قالب معمولی** که حس طرح را از بین برده است.

این اسکیل به ایجنت یاد می‌دهد مثل یک طراح و برنامه‌نویس رابط کاربری کار کند:

1. **طرح را برای فهمیدن منظورش بخواند.** ترتیب بخش‌ها، لوگو، رنگ مداد هر ناحیه و رفتارهایی را که از طرح فهمیده می‌شود ثبت کند. مثلاً نقطه‌های زیر بخش اصلی یعنی اسلایدر، کارت نیمه‌پیدا یعنی اسکرول افقی، و بیضی‌های رنگی یعنی فیلتر.
2. **محصول واقعی را بسازد:** منویی که روی موبایل کار کند، دکمه‌های اقدام روشن، فرم با اعتبارسنجی، و صفحهٔ موفقیت در پایان هر مسیر.
3. **روح نقاشی را نگه دارد:** خط جوهری لرزان، سایهٔ مداد رنگی و حروف دست‌نویس، بدون اینکه کند شود.

## نصب

**Claude Code** (یک دستور):

</div>

```text
/plugin install ui-ux-sketchbook --marketplace TssHack/ui-ux-sketchbook
```

<div dir="rtl">

**Codex، Cursor و بیش از ۴۰ ایجنت دیگر:**

</div>

```bash
npx skills add TssHack/ui-ux-sketchbook
```

<div dir="rtl">

**Hermes Agent** یا هر ایجنت دیگر با اسکریپت نصب. روی macOS و لینوکس:

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/TssHack/ui-ux-sketchbook/main/install.sh | sh -s -- --agent hermes
```

<div dir="rtl">

روی ویندوز (PowerShell):

</div>

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/TssHack/ui-ux-sketchbook/main/install.ps1))) -Agent hermes
```

<div dir="rtl">

گزینه‌های `--agent` این‌ها هستند: `claude`، `codex`، `cursor`، `hermes` و `all`. با `--project` اسکیل در همان پروژه نصب می‌شود و با `--dir` در هر پوشهٔ دلخواه. اسکریپت کل پوشهٔ اسکیل را کپی می‌کند، همراه با فایل‌های کمکی؛ دستور `hermes skills install` فقط خود `SKILL.md` را می‌گیرد.

بعد از نصب ایجنت را دوباره اجرا کنید. اسکیل وقتی درخواست شما به آن بخورد، خودش فعال می‌شود.

## نمونه درخواست‌ها

- «این طرح دستی سایت کافه‌مه. ازش یه سایت واقعی بساز که حس نقاشی رو داشته باشه و روی موبایل هم درست کار کنه. همه‌چیز توی یک فایل index.html.»
- «برای نانوایی خواهرم توی شیراز یه لندینگ‌پیج با حس دفترچهٔ نقاشی بساز؛ فارسی و راست‌چین، با فرم سفارش کیک.»
- «این وایرفریم کاغذی رو با همین ظاهر دست‌کشیده به یک اپ فلاتر برای اندروید و iOS تبدیل کن.»

## سه نسخه، یک ظاهر

| | جاوااسکریپت ساده | React / Next.js | فلاتر |
|---|---|---|---|
| **مناسب برای** | یک فایل HTML، سایت ایستا، بدون فریم‌ورک | وب‌اپ‌هایی که بزرگ‌تر می‌شوند | اندروید، iOS، وب، ویندوز، مک و لینوکس |
| **قاب و سایه** | `data-sketch data-tint` | `<SketchBox tint>` | `SketchBox(tint:)` |
| **تصویر** | `data-art="latte"` | `<Drawing spec={latte}>` | `SketchDrawing.named('latte')` |
| **حروف دست‌نویس** | `data-hand` | `<HandText>` | `HandText()` |
| **وابستگی** | ندارد | React | فقط Flutter SDK |

هر سه نسخه از همان ۱۵ تصویر آماده استفاده می‌کنند: آیس‌کافی، لاته، شکلات، سیب‌زمینی، پیتزا، بستنی، کیک، فنجان، کروسان، چیزکیک، همبرگر، پاستا، هات‌چاکلت، برگ پاییزی و دانهٔ قهوه. نسخهٔ فلاتر به‌صورت خودکار از روی نسخهٔ جاوااسکریپت ساخته می‌شود و CI مطمئن می‌شود این دو همیشه یکی بمانند.

## استانداردهای کیفیت

- در عرض‌های ۳۲۰، ۳۷۵، ۷۶۸، حدود ۹۲۰ و ۱۲۸۰ پیکسل درست کار می‌کند و صفحه به پهلو اسکرول نمی‌شود.
- هیچ فیلتر SVG ندارد و هر صفحه حداکثر حدود ۱۲۰۰ المان SVG دارد.
- مسیرهای اصلی از اول تا آخر امتحان می‌شوند، از جمله با یک بار ارسال فرم اشتباه.
- دسترس‌پذیر است: تصویرها برچسب دارند، حروف دست‌نویس یک بار توسط صفحه‌خوان خوانده می‌شوند و تنظیم «کاهش حرکت» رعایت می‌شود.
- راست‌به‌چپ درست است: حروف انگلیسی دست‌نویس چپ‌به‌راست می‌مانند، ترتیب نقاشی حفظ می‌شود و فرم‌ها اعداد فارسی را قبول می‌کنند.
